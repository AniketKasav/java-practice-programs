1. What will be the output of this code?

B. 8

2. What is the output of the recursive function?
static int fact(int n) {
 if(n == 1) return 1;
 return n * fact(n - 1);
}
public static void main(String[] args) {
 System.out.println(fact(4));
}
A. 24
B. 12
C. 16
D. 4
Answer: A. 24

8. What will happen in this program?
static int dp(int n) {
 if(n == 0) return 0;
 if(n == 1) return 1;
 return dp(n - 1) + dp(n - 2);
}
A. Dynamic Programming (optimized)
B. Recursion without optimization
C. Compilation error
D. Infinite loop
Answer: B. Recursion without optimization

10. What will be the output?
static int max(int[] arr) {
 int m = arr[0];
 for(int i : arr) {
 if(i > m) m = i;
 }
 return m;
}
public static void main(String[] args) {
 int[] arr = {3, 7, 2, 9};
 System.out.println(max(arr));
}
A. 7
B. 3
C. 9
D. 2
Answer: C. 9
